getItemsFail(rs, data) → {Array}

Description:

  • 由ORM逐筆函數(save、del)之回傳結果取出失敗者

    依w-orm系列規格，逐筆函數回傳與輸入等長保序之陣列，單筆失敗時整批仍resolve，該筆以ok為0並附err回報，須由呼叫端逐筆檢查。 主鍵未命中(save於autoInsert為false時查無主鍵、del查無主鍵)屬正常結果，其ok為1而以n為0表示，不視為失敗。 逐筆結果不含主鍵，故主鍵取自輸入同位置數據之id。

Source:
  • getItemsFail.mjs, line 30
Example
import getItemsFail from 'w-data-collector/src/getItemsFail.mjs'

let data = [{ id: 'id-a' }, { id: 'id-b' }, { id: 'id-c' }]
let rs = [
    { n: 1, nInserted: 1, nModified: 0, ok: 1 }, //插入
    { n: 0, nInserted: 0, nModified: 0, ok: 1 }, //主鍵未命中, 屬正常結果
    { n: 1, nInserted: 0, nModified: 0, ok: 0, err: 'E' }, //該筆失敗
]
console.log(getItemsFail(rs, data))
// => [ { k: 2, id: 'id-c', err: 'E' } ]
Parameters:
Name Type Description
rs Array

輸入ORM逐筆函數(save、del)之回傳結果陣列，非陣列時(未依規格之ORM)無從逐筆檢查而回傳空陣列
data Object | Array

輸入呼叫ORM逐筆函數時之數據物件或陣列，為單一物件時視為長度為1之陣列
Returns:

回傳失敗者陣列，各筆為{k,id,err}，k為該筆於輸入內之位置，id為輸入同位置數據之id，err為ORM回報之錯誤訊息(未附時為空字串)，無失敗者回傳空陣列

Type
Array
